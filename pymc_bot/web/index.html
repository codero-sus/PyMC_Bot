Player model train on playtime

idle

The Fabric mod in ./mod records your own playtime (position, look direction, block neighbourhood, nearby entities and every key you pressed) into pymc-playtime/dataset.jsonl. Train a model on it here — it checkpoints itself as it goes and can then play the bot (brain = trained).

Advanced training entities + items

Learn which entities and items your playtime actually contains and give each one its own inputs (how close, where relative to your view, how many, in your hand) instead of the coarse “hostile / passive” buckets. Needs a recording made with /pymc advanced on in the mod; the learned words are stored in the checkpoint, so the bot encodes the live world exactly the same way. Leave the sliders at 0 to use the defaults (24 entities, 32 items).

HTTP API
  • GET /api/status — bot, AI, stats, backends, Ollama health
  • PUT /api/config — partial config merge (JSON body)
  • POST /api/bot/start|stop|reconnect — connection control
  • POST /api/bot/chat {"message":"hi"}
  • POST /api/bot/action {"action":"wander"} or {"raw":"{...}"}
  • POST /api/ai/start|stop|step — the Ollama decision loop
  • WS /ws — live event / status frames
