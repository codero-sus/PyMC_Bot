HTTP API
  • GET /api/status — bot, AI, stats, backends, Ollama health
  • PUT /api/config — partial config merge (JSON body)
  • POST /api/bot/start|stop|reconnect — connection control
  • POST /api/bot/chat {"message":"hi"}
  • POST /api/bot/action {"action":"wander"} or {"raw":"{...}"}
  • POST /api/ai/start|stop|step — the Ollama decision loop
  • WS /ws — live event / status frames
PyMC_Bot runs a real Minecraft client through mineflayer (Node) and is driven from Python.
