Start Cortex on this machine, then Check Cortex. The bearer key is read from the environment variable named above when PyMC_Bot starts, never stored in the config.

Minecraft knowledge — let the AI look things up

Many models barely know Minecraft. The bot always knows the basics of every vanilla mob, and with web search on, the Ollama / Cortex brain can look up a mob, block, recipe or mechanic (the search action) and act on the answer in the same turn. Questions about one mob (hostile? damage? spawn time? which version added it?) are answered offline from the built-in mob database - it even knows mobs newer than mineflayer, like the 26.2 sulfur cube. Other questions go to the provider below; answers are cached.


      

      

        Bot behaviour — how the Ollama / Cortex brain plays and talks
        
Pick how the bot should behave. Behind each choice is a detailed player prompt that makes
          the LLM play like a real person: it keeps a goal, remembers what worked, answers people first and
          chats casually without spamming. If someone sincerely asks whether it is a bot, it says so.

🎓Player model train on playtime

        idle
      

      
The Fabric mod in ./mod records your own playtime (position, look direction,
        block neighbourhood, nearby entities and every key you pressed) into
        pymcbot/dataset.jsonl. Train a model on it here — it checkpoints itself
        as it goes and can then play the bot (brain = trained).


      

        
        
        
        
        
        
      


      

        Advanced training entities + items
        
Learn which entities and items your playtime actually
          contains and give each one its own inputs (how close, where relative to your view, how many, in
          your hand) instead of the coarse “hostile / passive” buckets. Needs a recording made with
          /pymcbot advanced on in the mod; the learned words are stored in the checkpoint, so the
          bot encodes the live world exactly the same way. Leave the sliders at 0 to use the defaults
          (24 entities, 32 items).

🛠️Skills —

        
      

      
Bigger jobs a player does: chop a tree, mine ore, farm, craft, smelt, fill a chest, trade,
        build a shelter, go home… Click one to fill in its options, double-click to run it straight away.
        The AI can use every skill too (switches in AI brain still apply).

      

      

        
        
        
        
      

      

    


    
    

      

        
🛡️Autopilot —

        
      

      
Reflexes every bot has on its own, so it can be left alone: respawn, swim up for air,
        put out fire, totem, run at low health, eat, wear better armour, fight back, sleep at night,
        torches in the dark, pick up items, toss junk… Emergencies interrupt; chores wait until the bot is idle.

        HTTP API
